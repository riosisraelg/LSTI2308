# Actividad 4: Redes de Datos, Seguridad y Sistemas Distribuidos

Este proyecto corresponde a la **Actividad 4** de la materia de **Sistemas Operativos (LSTI2308)**.

## Objetivo
Diseñar e implementar una red de datos segura y distribuida en Linux, integrando protocolos TCP/IP, medidas de seguridad informática (Firewalls, SSL/TLS) y analizando el funcionamiento de sistemas Peer-to-Peer (P2P).

## Instrucciones de la Actividad

### Resumen de Tareas:
- **Parte 1: Diseño y configuración de red**: Esquema OSI, direcciones IP estáticas, servicios SSH y HTTP.
- **Parte 2: Seguridad**: Configuración de Firewalls (ufw/iptables), llaves SSH, HTTPS (SSL/TLS) y análisis con nmap/lynis.
- **Parte 3: Sistemas Distribuidos y P2P**: Configuración de sistemas de archivos distribuidos y exploración de redes P2P.
