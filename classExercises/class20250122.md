# Comandos de Unix/Linux

Esta tabla contiene los comandos más comunes utilizados en sistemas Unix y Linux.

## Navegación y Archivos

| Comando | Descripción | Ejemplo |
| :--- | :--- | :--- |
| `ls` | Lista los archivos y directorios en la ubicación actual | `ls -la` |
| `cd` | Cambia el directorio actual | `cd Documents` |
| `pwd` | Muestra la ruta completa del directorio actual | `pwd` |
| `mkdir` | Crea un nuevo directorio | `mkdir nuevo_proyecto` |
| `rm` | Elimina archivos o directorios | `rm archivo.txt` |
| `cp` | Copia archivos o directorios | `cp archivo.txt copia.txt` |
| `mv` | Mueve o renombra archivos o directorios | `mv viejo.txt nuevo.txt` |
| `touch` | Crea un archivo vacío o actualiza su fecha | `touch index.html` |

## Visualización y Edición de Texto

| Comando | Descripción | Ejemplo |
| :--- | :--- | :--- |
| `cat` | Muestra el contenido completo de un archivo | `cat lista.txt` |
| `head` | Muestra las primeras líneas de un archivo | `head -n 5 log.txt` |
| `tail` | Muestra las últimas líneas de un archivo | `tail -f log.txt` |
| `grep` | Busca un patrón de texto dentro de archivos | `grep "error" sys.log` |
| `less` | Permite visualizar un archivo de forma paginada | `less archivo_largo.txt` |
| `nano` / `vim` | Editores de texto integrados en la terminal | `nano config.conf` |

## Información del Sistema y Procesos

| Comando | Descripción | Ejemplo |
| :--- | :--- | :--- |
| `top` / `htop` | Muestra los procesos en tiempo real y uso de recursos | `top` |
| `df` | Muestra el uso de espacio en disco | `df -h` |
| `du` | Muestra el tamaño de un archivo o directorio | `du -sh .` |
| `ps` | Muestra información sobre los procesos actuales | `ps aux` |
| `kill` | Termina un proceso por su ID | `kill 1234` |
| `uname` | Muestra información del sistema operativo | `uname -a` |

## Otros Comandos Útiles

| Comando | Descripción | Ejemplo |
| :--- | :--- | :--- |
| `sudo` | Ejecuta un comando con privilegios de superusuario | `sudo apt update` |
| `chmod` | Cambia los permisos de un archivo o directorio | `chmod +x script.sh` |
| `chown` | Cambia el dueño de un archivo o directorio | `chown user:group file` |
| `man` | Muestra el manual de un comando | `man ls` |
| `history` | Muestra el historial de comandos ejecutados | `history` |
| `clear` | Limpia la pantalla de la terminal | `clear` |

## Comparativa de Sistemas Unix y Unix-like

A continuación se presenta una comparativa de los sistemas más representativos siguiendo las columnas solicitadas:

| Sistema | Base / Modelo | Enfoque | Ventajas | Desventajas | Casos de Uso | Seguridad | Estabilidad | Actualización | Facilidad de Uso | Link de descarga |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| **Ubuntu** | Debian (Linux) | Usuarios generales y servidores | Gran comunidad, facilidad de instalación | Telemetría (en algunas versiones), Snap | Escritorio, Servidores web, Nube | Alta | Muy Alta (LTS) | Semestral o cada 2 años | Muy Alta | [Original](https://ubuntu.com/download) |
| **FreeBSD** | Berkeley Software Distribution (BSD) | Rendimiento y redes | Stack de red optimizado, robustez, ZFS nativo | Curva de aprendizaje, soporte de hardware limitado | Servidores de red, Firewalls (pfSense) | Excelente | Legendaria | Continua y por versiones | Media | [Original](https://www.freebsd.org/where/) |
| **Red Hat Enterprise (RHEL)** | Fedora/Linux | Entorno corporativo | Soporte profesional, certificación de hardware | Costo de licencia (aunque hay versión gratuita para devs) | Servidores críticos de misión real | Nivel corporativo (SELinux) | Excepcional | Ciclos largos (10 años soporte) | Media | [Original](https://developers.redhat.com/products/rhel/download) |
| **macOS** | Darwin (BSD / Mach) / Unix Certificado | Productividad y diseño | Ecosistema Apple, gran interfaz, terminal Unix real | Hardware cerrado, costo elevado | Desarrollo de software, Diseño | Muy Alta | Alta | Anual (sistema), constante (apps) | Muy Alta | [App Store](https://www.apple.com/macos/) |
| **Arch Linux** | Independiente (Linux) | "Keep It Simple" / Personalización | Software más reciente (Rolling Release), personalización total | Difícil de instalar, puede romperse con actualizaciones | Usuarios avanzados, aprendizaje | Alta (configurable) | Media (depende del usuario) | Rolling Release (diaria) | Baja (manual) | [Original](https://archlinux.org/download/) |
| **CentOS Stream** | RHEL (Linux) | Pre-RHEL, desarrollo | Compatibilidad con RHEL, robusto | Ya no es "clon" estable de RHEL (es upstream) | Entornos de pruebas corporativos | Alta | Alta | Continua | Media | [Original](https://www.centos.org/download/) |
